# 交接包本身的验收（区别于 Codex 工程 Gate）

交接包的质量检查只包括：

- 文件数量、清单哈希、全部 JSON 可解析；原资料及 Demo JSON 一致；没有残缺引用。
- 原架构的 8 类设计 Schema 曾经验证通过；本交接预检不重复宣称游戏引擎已经实现。
- 已包含 Copilot/Codex 入口 `AGENTS.md`、一次性任务、已锁原则、接口契约、DEMO、开发计划、测试用例、已知缺口。
- 提供能真实运行的**资料预检命令**；P1 gate 的失败测试被明确保留。

用命令 `node scripts/preflight.mjs` 检查当前文件。如果该命令失败，说明资料被修改或包内容损坏，**不可进入实现直到定位原因**。

完成 P1 后，只有实际源码和真实测试结果可以构成软件验收证据。
